# 🌐 Web Scraping Project

## 📖 Description

This module extracts book-related information from an open-source website using **BeautifulSoup** and converts the scraped content into a structured DataFrame for analysis.

## ✨ Functionalities

- Extract book titles
- Extract book prices
- Extract product ratings
- Store scraped data into DataFrame
- Perform statistical analysis
- Sort data in ascending and descending order

## 📊 Data Operations Performed

- `head()`
- `mean()`
- `sort_values()`
- `std()`

## 🛠️ Libraries Used

- requests
- beautifulsoup4
- pandas

## ▶️ Execution

```bash
python web_scrapping.py
```

- Perform salary analysis
- Sort merged records

- Foreign Key

- Data Merging
- Relational Data Handling

## 📊 Statistical Operations

## ▶️ Execution

