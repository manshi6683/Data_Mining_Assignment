Data analysis operations

Statistical calculations

📂 Project Modules
1️⃣ Web Scraping Project

Extracts book data from an open-source website using BeautifulSoup and converts it into a structured DataFrame.

✨ Features
Scrape book titles, prices, and ratings
Convert scraped data into DataFrame
Calculate mean price
Perform sorting operations
Standard deviation analysis
🛠️ Technologies Used
Python
BeautifulSoup
Requests
Pandas
